# 🌍 GlobeTrotter

GlobeTrotter is a full-stack travel planning and itinerary management application designed to help users create trips, explore destinations, and organize personalized travel itineraries.

## ✨ Features

- Create and manage trips
- Explore and manage destinations
- Create personalized itineraries
- Organize activities day-by-day
- Manage checklists and travel documents
- Reservation and notification management
- Full-stack REST API
- Database-backed application

## 🛠️ Tech Stack

### Frontend
- React.js
- TypeScript
- Vite

### Backend
- Node.js
- Express.js
- TypeScript
- REST API

### Database
- PostgreSQL
- Prisma ORM

### Development Tools
- Git
- GitHub

- npm
